# Repurpose into a video script

Written text and spoken video are different jobs. A script is not the article read aloud: it
opens on the payoff, cuts the context, and gives the viewer a reason to stay every few
seconds.

## Input

The source piece: by default the final article for the slug in
`projects/content-engine/content/`, or any file, URL or pasted text the user gives. Ask
which format if the user did not say: **short** (under 60 seconds) or **long-form**.

Read `projects/content-engine/your-setup/brand-and-voice.md` first.

## Rules for both formats

- The first seconds decide everything. Open on the claim, the result or the question.
  No greeting, no "in this video".
- Every sentence moves the story forward. Cut context the viewer does not need.
- Write for the ear: short sentences, plain words, one idea each.
- Only what the source says. Every number and claim is in the source piece.
- The hook is specific to this piece. A line that fits any video ("nobody talks about this")
  is not a hook.

## Short (Shorts, Reels, TikTok)

| Part | Job | Length |
|---|---|---|
| Hook | The claim or result, in the first 1 to 3 seconds | 1 line |
| Context | Why it matters, only what is needed | 1 to 2 lines |
| Main insight | The one idea | 2 to 3 lines |
| Support | One example or number | 1 to 2 lines |
| Payoff | Close the loop the hook opened | 1 line |
| Call to action | One, or a line that loops back to the start | 1 line |

One idea per short. If the article has four, that is four shorts: list the other three as
follow-ups.

## Long-form (YouTube)

1. **Hook** and **promise** in the first 30 seconds: what the viewer will be able to do by
   the end.
2. **The problem,** briefly.
3. **Main sections,** in the order a viewer needs them, not the order the article used.
4. **A re-hook at the start of each section:** what is coming and why it is worth staying.
5. **Payoff,** then one call to action.

## Output

Write `projects/content-engine/content/9-repurposed/{slug}/video-short.md` or
`video-long.md`:

- the hook, with two alternatives
- the full script, split into the parts above
- a note per part on what is on screen (talking head, screen recording, a chart from the
  article)
- for long-form: a title and a one-line description

**A script is not a video.** Say so in the closing message, in those words, and say what
the video still needs: a recording in the person's own voice, or their go-ahead to use a
voice or avatar tool they already have. Offer to cut the recording if this folder has an
editing setup. Never present the script as the finished piece.

Never use em dashes.
