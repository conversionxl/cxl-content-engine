# A made-up Search Console export

`acme-search-console.csv` holds invented numbers for the fictional brand Acme Deals. The
rows were written to show each pattern the engine looks for: a page that is seen but not
clicked, pages close to page one, a page losing ground, and queries with no page of their
own. Two rows are branded queries, which the engine leaves out.

Each row covers the last 28 days, with clicks and impressions for the 28 days before.
